# VETRIX ERP - Project Instructions

## Goal

Build and maintain a production-grade ERP.

Always prioritize correctness over speed.

---

## Context Policy

Read the minimum number of files.

Never read the whole project.

Search first.

Read only files directly related to the task.

Avoid loading large files unless absolutely necessary.

---

## Editing Policy

Modify only requested files.

Never refactor unrelated code.

Never rename files unless requested.

Never rewrite working code.

Keep changes as small as possible.

---

## Code Style

Reuse existing components.

Avoid duplicate code.

Prefer existing utilities.

Keep functions focused.

Keep components small.

---

## Performance

Minimize token usage.

Minimize context size.

Do not inspect unrelated folders.

Avoid repeated searches.

---

## Before Coding

Understand the task.

Locate affected files.

Explain the implementation plan briefly.

Then implement.

---

## After Coding

Run only relevant tests.

Run lint only if modified files require it.

Summarize changes.

Do not explain unrelated code.

---

## Forbidden

Do not scan the repository.

Do not read node_modules.

Do not read build.

Do not read dist.

Do not inspect generated files.

Do not modify package versions unless requested.

---

## Preferred Workflow

Search

↓

Read minimal files

↓

Implement

↓

Verify

↓

Finish
